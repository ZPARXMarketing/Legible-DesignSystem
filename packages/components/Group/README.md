Group sets related items together and keeps groups visibly apart, by spacing alone.

Provide an optional `label` and the items as `children`. Items inside sit `gap-item` apart; wrap groups in `.lg-groups` to space them `gap-group` apart, and sections in `.lg-sections` for `gap-section`. Proximity is the strongest grouping cue, so no box or rule is needed. Keep a group to about four items; working memory holds three to five chunks.
