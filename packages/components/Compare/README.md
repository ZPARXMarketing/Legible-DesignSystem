Compare lays options side by side against the same criteria, for choosing.

Provide `options` (columns), `criteria` (row headers, `scope="row"`), `values` (one row per criterion), optional `pick` (index of the recommended option), `pickLabel`, `numeric` (row indexes right-aligned) and `caption`. The pick is marked with a check and a word, never color alone. A missing value shows "—", never a guess. The criteria column stays put while the options scroll on a narrow screen.
